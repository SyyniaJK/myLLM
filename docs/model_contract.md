# 最小模型与显式契约

本平台名为 EdgeInferenceLab。TP-MPPO 是第一种接入算法；物理模型、评价和能耗统计由所有算法共用。

## 模型范围

- 固定时隙，时隙结束时统一调度；不设跨时隙等待队列。
- 用户没有本地推理能力。动作 0 为拒绝，1…J 为卸载节点。
- 每个用户最多一个未结束请求；收到输出或失败通知后开始新的指数分布 thinking time。
- 同一节点同一时隙的请求组成同步批次；所有 prompt 上传完成后开始 prefill，使用最大输入和最大实际输出长度。无动态退出、连续批处理、推测解码。
- 节点在上传、推理、反馈阶段均被本批占用，释放时间使用绝对秒数。GPU 计算能耗只在 prefill/decode 时段增加。
- 输出 cap、输入长度、SLO 在决策前可见。实际输出由 cap×随机比例得到，只在环境内使用；actor 的观测中没有实际输出或未来完成时间。
- 观测为每用户三个任务字段、两套完整上下行信道、节点 idle 标记；维数为 3N+2NJ+J。idle 在调度时刻判断。

## 单位与公式

时间 s，频率 Hz，功率 W，能量 J，数据 bit，显存 byte；GB 统一为 10^9 byte，不混用 GiB。

无线模型使用论文的 R=beta B log2(1+ph/psi)，psi 是总噪声功率。上下行各自采样指数功率衰落；距离增益为 (A_d c/(4π f_c d))^d_e。不使用人为最小距离、增益截断或安全带宽。

推理时延严格采用 TP-MPPO.md II-B 的 prefill 与 decode FLOPs 表达式除以 F。显存为 2×参数量 + 4hLb(s+o)，是原文的 FP16 MHA 近似，不声称等价于每个真实 GQA 模型的内存。

多个 GPU 的显存和理想算力线性汇总。这是资源敏感性近似，不是张量并行性能模型。

## 资源分配与失败语义

上行执行 P2 闭式解。下行执行 P3 最小需求排序、最大数量选取，非正剩余时间不可行。沿用导师代码将剩余带宽按最小需求比例补给已选中用户；选中集合不变。

下行未分配带宽的结果在推理完成时丢弃并返回零载荷失败通知。通知能耗忽略，用户从该时刻开始 thinking time。这是使闭环系统定义完整的显式补全假设，原文没有说明未获下行资源的请求如何结束。

OOM 为峰值显存超过容量。保持论文的实际输出长度显存公式，模拟器在上传结束后进行解析峰值预留判定，失败批次不执行部分 GPU 推理。这是解析仿真语义；未模拟真实设备中途 OOM 的功率轨迹。

Action Mask 仅使用请求存在性与节点 idle。各用户独立采样时不添加联合显存屏蔽。OOM 仍参与论文奖励。整数范围内但越过掩码的动作明确失败，不静默改派。

## 指标与统计边界

- `inference_completed`：无 OOM、已经解析完成 GPU 推理的请求。
- `throughput`：输出真正返回的请求，不能把尚未反馈或零带宽结果计为完成。
- `goodput`：返回且满足 E2E SLO 的请求。P3 的 SLO 等式在等价带宽空间判断，避免浮点数加减误差制造超时。
- `goodput_ratio`：Goodput/产生请求数；无请求时定义为 0。
- `reward`：每时隙 (good_weight×goodput−oom_weight×OOM)/请求数；无请求为 0。G3 不改 reward。
- `gpu_ttft_s`、`gpu_tpot_s`：GPU 阶段指标；不将它们冒称为客户端流式 TTFT/TPOT。结果按完整输出反馈。
- `goodput`/`throughput` 按本 episode 产生请求的 cohort 结算，包含窗口末尾批次的最终结果。
- `*_within_window` 只计 response_s≤Kτ 的已结束请求，`pending_at_horizon` 单独列出。主固定能耗窗口为 [0,Kτ]；尾部单独输出。

论文图4的 Throughput–Goodput 差距涉及未获下行带宽请求的处理。当前明确的丢弃语义下，TP-MPPO 的已返回请求通常均满足 SLO；不会把“完成 GPU 推理”改名为 Throughput 来人为制造差距。

## 能耗契约

E_up=Σ p_up T_up，E_down=Σ p_down T_down。

E_GPU=J×G×P_idle×H + Σ_batches G[(P_prefill−P_idle)T_prefill+(P_decode−P_idle)T_decode]。

所有相位按绝对时间与统计窗口求交。整批 GPU 能耗计一次，不按用户重复相加。空闲基线已包含活跃时段的 P_idle，因此相位只加增量。未模拟网络基础设施、CPU、制冷和调度器功耗。

15/60/45 W 是可替换的演示相位功率，不是设备实测。提供 `integrate-power` 从实测 time_s,power_w CSV 做梯形积分；尚未集成硬件采样器。

## 编程契约

入口类型、形状、单位及定义域用显式断言表达。契约失效直接报错，不补值、不重试、不缩放非法外部动作。随机种子使用显式独立 RNG，不依赖进程的全局 NumPy 随机状态。

带宽之和允许一个可表示浮点步长的舍入误差（`nextafter(1,+∞)`），没有人为的百分比余量。该比较只验证归一化计算的数值等式，不增加可调资源。零方差归一化坐标规定单位尺度，不使用隐式 epsilon。

PPO 的 0.2 策略裁剪、0.5 梯度裁剪、Adam 的 1e-5 是原算法参数，保留在明确配置/优化器中，与无线资源安全门限无关。
