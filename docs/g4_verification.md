# G4 完成记录

完成日期：2026-10-28。正式结果目录为 `results/g4/benchmark`，机器可读核对记录为该目录的 `verification.json`。

## 已运行的实验

- 六种方法：TP-MPPO、无掩码 TP-PPO、合法随机、最强信道、批次均衡、cap 显存贪心。
- 五个规模配置、两种负载模式、三个策略重复、十个测试场景，共 **1800 次完整评估**；格点完整且没有重复。
- 复用 G1–G3 的 15 个 TP-MPPO 策略；新增训练 15 个 TP-PPO 策略。每个学习方法的每次训练均为 **65536 步**，新增训练合计 983040 步。
- 保存 50 个场景和 1800 份动作/reward 轨迹。固定负载逐字段核对外生请求；闭环负载保留完成时间对后续到达的影响。

两种学习方法均在闭环负载训练；固定负载结果是冻结策略的迁移评估。后四种基础对照使用本平台明确公开的规则，不替代原论文未完整公开的全部比较算法。

- **73 项测试通过**，覆盖原有物理/能耗契约以及新增无掩码训练、场景保存、方法接口、同预算检查、统计与完整评估流程。
- **180 次自动精确重放全部通过**：每个 case/mode/method/replicate 的首场景比较动作、reward、请求、批次和物理指标。
- 另外从保存记录重放 `default/fixed/tp_mppo/replicate_1/scenario_40001`，与原记录完全一致，结果在 `results/g4/replay_example/replay.json`。
- 从 1800 条原始记录重新生成汇总；`summary.json`、`summary.csv`、`statistics.csv`、两份配对差文件和 `report.md` 均与重建前逐字节一致。
- 自定义策略及自定义带宽分配器已通过端到端测试；方法执行顺序不会改变科学指标。
- 四组图均已检查实际 PNG：服务量与能耗、规模变化、配对方法差、同预算训练曲线。标签、图例和区间没有裁切或遮挡，均同时导出 PNG、SVG、PDF。

CPU 决策墙钟耗时只作诊断，精确重放排除该字段。测试中 Gymnasium 对无界观测空间上界给出一个提示；空间上界按模型定义保留，没有添加任意截断。

## 当前结果的含义

默认配置的闭环负载下，每 200 秒窗口的平均合规请求数如下；完整区间与各项能耗见正式报告。

| 方法 | 平均窗口 Goodput | 模拟能耗（J） |
|---|---:|---:|
| TP-MPPO | 984.967 | 12640.945 |
| TP-PPO | 948.100 | 12529.324 |
| 合法随机 | 825.800 | 11940.884 |
| 最强信道 | 1056.300 | 13032.587 |
| 批次均衡 | 1095.100 | 12873.843 |
| cap 显存贪心 | 1096.900 | 12765.508 |

在当前配置与训练预算下，TP-MPPO 的平均服务量高于无掩码 PPO 和随机策略，低于三种确定性规则。因此这些实验支持基线平台可运行、可比较、可重放；尚不能支持 TP-MPPO 优于强启发式或新方法具备论文创新性的结论。

能耗仍由统一相位功率模型估算，尚未以真实 GPU 校准。统计使用三个训练 seed 与十个场景的交叉重采样，区间属于有限样本探索性描述。后续算法必须继续与批次均衡、cap 贪心等对照公平比较。
